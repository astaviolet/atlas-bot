  https://github.com/astaviolet/atlas-bot.git

Comando de push:

  timeout 120 git -c credential.helper= push -q "https://x-access-token:${TOKEN}@github.com/astaviolet/atlas-bot.git" main
  unset TOKEN

NUNCA copiar a URL de memoria nem de nota: uma reticencia no meio da string
vira "repository not found" e o push falha em silencio se o && estiver antes.
